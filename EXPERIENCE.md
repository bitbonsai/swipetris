# Feel

1980s arcade, on a phone, with respect for the player. Loads instantly, starts in one tap, ends a run in about thirty seconds. Uppercase Press Start 2P, chunky pieces, heartbeat audio instead of looping music. Losing should make you tap "again" before you think about it.

# Principles

- One thumb does everything. If a control needs two hands or precision, redesign it.
- Free forever. Ads, coins, subscriptions, and upsells are off the table permanently.
- Fair by construction: everyone plays the same board, only the best run counts, CPU benchmark rows are labeled as such.
- Private by default: gameplay stays on the device; the server only ever sees initials, score, and anti-cheat metadata.
- Light: no build step, no framework churn, vendored dependencies, works offline.
- Fun is the feature. Anything that adds friction to a thirty-second session gets cut.
